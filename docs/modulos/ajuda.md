# Ajuda

> Onde ficam as instruções de uso do FundHub - um tutorial por módulo.

## O que dá para fazer aqui

- Ver a lista dos módulos que têm tutorial e que você pode acessar.
- Abrir o tutorial de um módulo e ler o passo a passo, as regras que o sistema
  aplica e as ligações com outras telas.

Cada tela do sistema que tem tutorial mostra um botão de ajuda no canto
superior direito, ao lado da engrenagem de configurações. Ele abre direto o
tutorial daquela tela.

## Quem pode o quê

A Ajuda é de todo mundo. Você vê o tutorial de um módulo se enxerga aquele
módulo no menu - nada além disso. Quem não tem acesso a uma tela também não
precisa do manual dela.

## Passo a passo

### Ler o tutorial de uma tela

1. Na tela em que você está, clique no botão de **ajuda** (o ponto de
   interrogação) no canto superior direito.
2. O tutorial abre numa página própria. Você pode deixá-la aberta numa aba e
   voltar à tela em outra.
3. No topo do tutorial há dois botões: **Voltar para** a tela de onde você
   veio e **Todos os tutoriais**, que abre a lista completa.
4. A lista completa também está em **Ajuda**, no menu lateral, na seção
   Documentação.

### Pedir a correção de um texto

O tutorial está errado ou desatualizado? Avise a Gerência de Ensino
Fundamental. O texto é corrigido e passa a valer para todo mundo no acesso
seguinte.

## Regras que o sistema aplica

- Um endereço de ajuda para um módulo que você não enxerga responde
  "Página não encontrada" - igual a um endereço que não existe.
- Se o texto de um tutorial ainda não foi publicado, a tela avisa em vez de
  ficar em branco.

## Ligações com outros módulos

A lista de tutoriais vem do mesmo lugar que monta o menu lateral: você vê
aqui exatamente os módulos que vê lá.

## Perguntas frequentes

**Por que alguns módulos não aparecem na Ajuda?**
Ou você não tem acesso a eles, ou o tutorial deles ainda não foi escrito.

**A "Documentação técnica" é a mesma coisa?**
Não. Aquela descreve como o sistema funciona por dentro e é só para quem
mantém o código. A Ajuda é para quem usa.
